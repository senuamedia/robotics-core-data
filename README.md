# Senua AI Robotics Core: open data

Datasets generated by the Senua AI Robotics Core, published as open data: so that anyone can check our films and
claims against the numbers that produced them, use the data in their own work, and, once the same runs are made on
real hardware, see the gap between simulation and reality measured against a forecast we published first.

| Dataset | What it is |
|---|---|
| [`datasets/shape-sorter`](datasets/shape-sorter/README.md) | An SO-101 robot arm picks five shapes and drops each through its cutout in a raised board: 48.4 seconds, every 6.25 ms |
| [`datasets/servo-recordings`](datasets/servo-recordings/README.md) | Two public recordings of real SO-100 and SO-101 arms (Apache-2.0, credited), every joint read by the Senua AI engine into causal states, on ARM and x86 processors |
| [`datasets/so-arm-recordings`](datasets/so-arm-recordings/README.md) | Two hundred public recordings of real SO-100 and SO-101 arms from as many authors (credited), each read by the Senua AI engine; and every arm the simulator test covers set against the Robotics Core simulator, out of the box and calibrated to that arm: the sim-to-real gap arm by arm, beside a published MuJoCo study on the same recording |
| [`datasets/so-arm-recordings-remeasured`](datasets/so-arm-recordings-remeasured/README.md) | The same real arms set against the simulator again, with the simulator calibrating itself to each arm from the first half of its own recording (its command latency, each joint's offset and sag under load, its jaw's stop), and 26 arms never used before: the sim-to-real gap arm by arm |
| [`datasets/weight-lifted`](datasets/weight-lifted/README.md) | A stock SO-101 lifting known weights (the public Neural Actuation Dataset, credited): the weight read from the arm's own joint positions through the simulator, never shown a weight |

Each simulation dataset holds the simulation's input, its complete physics output, the command streams for the real robot, the data
behind every frame and number of the film made from it, a sim-to-real forecast stated before the real robot is run, the
methods and the physics applied, and the checks that verified every number. Every claim in a dataset's documents is
cited: each physics law to the peer-reviewed research it follows, each hardware, price and licence fact to its
publisher, and each measured fact to the file that holds it (the dataset's `REFERENCES.md`).

Every generated value is a whole number in a stated unit; each dataset's README explains every file and every column, and its
`SHA256SUMS` lists every file. The shape sorter's data was generated on one processor of an ordinary cloud computer,
with no GPU and no machine-learning or language model of any kind
([`provenance/GENERATION.md`](datasets/shape-sorter/provenance/GENERATION.md)). Values described as "an internal
Senua AI representation" are the engine's own and are not explained further. The engine and its code are not part of
this repository.
